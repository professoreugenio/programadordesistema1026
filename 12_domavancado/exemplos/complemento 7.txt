7. Armazenamento com localStorage e JSON
💾 O que é localStorage?
localStorage é um recurso da Web Storage API que permite guardar pares de chave e valor no navegador.

Os valores são armazenados como strings e associados à origem da página.

O armazenamento é adequado a pequenos projetos didáticos, preferências e informações não sensíveis, mas não substitui um banco de dados de servidor.

📥 Salvando informações
localStorage.setItem("tema", "escuro");
📤 Recuperando informações
const tema = localStorage.getItem("tema");
console.log(tema);
🗑️ Removendo uma informação
localStorage.removeItem("tema");
🔄 Convertendo arrays em JSON
JSON significa JavaScript Object Notation, um formato textual utilizado para representar dados estruturados.

Utilizaremos JSON.stringify() para transformar o array em texto e JSON.parse() para recuperar os dados.

const produtos = [
    { codigo: 101, nome: "Mouse" }
];

localStorage.setItem(
    "produtos",
    JSON.stringify(produtos)
);
📚 Recuperando o array
const texto = localStorage.getItem("produtos");

const lista = texto === null
    ? []
    : JSON.parse(texto);

console.log(lista);
🚨 Tratando possíveis erros
Operações com localStorage podem falhar por restrições de acesso, armazenamento ou dados inválidos.

Por isso, utilizaremos try...catch.

try {
    const texto = localStorage.getItem("produtos");

    const lista = texto === null
        ? []
        : JSON.parse(texto);

    console.log(lista);
} catch (erro) {
    console.error("Falha ao recuperar dados:", erro.message);
}
